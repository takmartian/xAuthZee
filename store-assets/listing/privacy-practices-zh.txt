Chrome Web Store 隐私权实务规范 —— 各字段答案（纯文本）

每段都是可以直接复制贴到表单对应字段的完整回答。


【1. activeTab 权限的理由】

此扩展只在用户主动点击工具栏图标或扫描按钮时，才读取当前标签页的 URL，并仅在该页面截取二维码画面。我们使用 activeTab 而非 all_urls（host permission）以遵守最小权限原则：扩展不主动监听或读取任何标签页，只在用户明确操作时工作。读取当前 URL 是为了「绑定当前网站」功能（把账号和域名关联，让该网站访问时浮层顶部自动出现对应验证码），以及扫描按钮触发的二维码截取。

【2. alarms 权限的理由】

此扩展用 chrome.alarms 调度主密码的自动锁定定时器。当用户启用了主密码加密功能并在设置中选了一个自动锁超时（5/15/30/60 分钟或从不），扩展会注册一个名为 xz-auto-lock 的 alarm，到点自动清除 session storage 里的派生密钥并把状态切回 locked。alarms 是浏览器原生的定时 API，比 setTimeout 更可靠——它能在 Service Worker 被回收后仍然按点触发。扩展没有用 alarms 做任何其他事情。

【3. idle 权限的理由】

此扩展监听 chrome.idle.onStateChanged 事件，仅在系统进入 'locked' 状态时立即触发上锁。当用户的操作系统锁屏（macOS 锁屏、Windows Win+L、Linux 锁屏）时，浏览器会广播这个事件，扩展收到后立刻清空 session key、把锁状态切回 locked，确保用户离开座位后即使忘记关浏览器，2FA 密钥也不会以 unlocked 状态留在内存里。idle 事件不发送任何数据给扩展外部。

【4. scripting 权限的理由】

此扩展在用户点击扫描按钮时，按需调用 chrome.scripting.executeScript 注入一个内容脚本到当前标签页。这个内容脚本的功能是显示一个二维码区域选择遮罩——让用户拖一个框框住页面上的二维码，然后用 jsQR 解析。注入是按需的（用户点了扫描才注入，不在所有标签页后台运行），注入范围严格限定在用户当前操作的标签页。扫描完成后注入的脚本即完成任务，不需要长期驻留。

【5. storage 权限的理由】

此扩展用 chrome.storage.sync 持久化所有用户数据：账号列表（issuer、label、secret、algorithm、digits、period、domains）、加密相关记录（salt、verifier 密文、KDF 参数）、偏好（浮层开关、宽检测、禁用域名列表、自动锁超时）。sync 意味着用户登录同一 Google 账号的多台设备上数据会自动同步（这是浏览器自带的同步机制，扩展自己不接触任何外部服务器）。同时用 chrome.storage.session 存 unlocked 态下的派生密钥——session storage 不会同步、关闭浏览器即清空，这是主密码功能的基础。没有 storage 权限，扩展无法保存任何用户数据。

【6. 远端程式码的理由】

此扩展不使用任何远端程式码。所有 JavaScript 都打包在商店上传的 zip 里、由 Chrome 签名验证。WXT 编译时把 lib、components、entrypoints 等所有源码静态打包进扩展，没有 eval、没有动态 import 外部脚本、没有 WebAssembly 模块动态加载、没有从 CDN 或任何外部域拉取资源。打开扩展的源代码就可以完整看到所有可执行代码。

【7. 网站存取权限的理由】

此扩展不使用 host permission（不申请 <all_urls> 或具体域名模式）。我们用 activeTab 权限代替——只在用户明确点击工具栏图标时获得当前标签页的临时访问权。Chrome MV3 文档明确推荐用 activeTab 代替 host permission 来实现「按需访问」的场景，这正是本扩展的需求：扫描按钮、绑定当前网站、OTP 浮层触发——所有网站访问都发生在用户明确操作的那一瞬间。

【8. 单一用途说明】

此扩展的唯一用途是 TOTP（基于时间的一次性密码，RFC 6238）动态验证码管理：在浏览器中安全存储用户的 2FA 账号密钥、在用户访问绑定的网站时自动浮现对应验证码、点击或一键填入到页面的 OTP 输入框。扩展不做其他任何事情：没有密码管理、没有笔记、没有同步通讯录、没有社交分享、没有广告拦截、没有页面修改器、没有自动填充表单（除了 OTP 输入框这一种专用场景）。所有功能都围绕 TOTP 这一个核心场景。


【9. 数据使用情形合规性确认】

我已确认本扩展遵守 Chrome Web Store Developer Program Policies。本扩展不收集、不使用、不传输任何用户个人数据：所有账号数据通过 chrome.storage.sync 存在用户本地，并通过浏览器自身的同步机制在用户自己的多设备间同步，扩展自身不接触任何外部服务器；没有任何分析、追踪、广告、崩溃报告或第三方 SDK；不向任何第三方出售或共享数据。
